# Privacy rules (non-negotiable)
- User transaction data never leaves the browser. No fetch/XHR/WebSocket/beacon/analytics with user data.
- No third-party scripts that see user data. Fonts and assets are self-hosted.
- Persisted data (if any) uses localStorage only, with a visible "Clear everything" control.
- Sample data is fully fictional. Exported images must not reveal exact amounts, names or phone numbers.
